# مغز پژوهشی «تحلیل تکنیکال ایران» / IranSignal

این مخزن عمومی است؛ فقط داده و یادداشت **قابل انتشار عمومی** در آن نگهداری شود.

## ساختار
- `research/knowledge.json`: واژگان، پرسش‌ها، فرضیه‌ها، سیگنال‌ها و یافته‌های دارای شناسه.
- `research/methodology.md`: روش‌شناسی، قواعد اعتبارسنجی و بازنگری.
- `research/reports/{daily,weekly,monthly}/`: گزارش‌های تولیدشده خودکار و دارای تاریخ.
- `fa/radar/`: نماهای عمومی گزارش‌های روزانه، هفتگی و ماهانه.
- `fa/research/`: جست‌وجو در گزارش‌ها و پرونده‌ها.
- `daily/manifest.json`: آرشیو قدیمی؛ تنها `status=published` وارد خلاصه‌ساز می‌شود.
- `data/news/candidates.json`: خبرهای خام و **تأییدنشده**؛ برای خروجی خودکار منبع احرازشده محسوب نمی‌شوند.

## وضعیت‌ها
`candidate_unverified`, `needs_review`, `verified_observation`, `open_question`, `supported_hypothesis`, `rejected_hypothesis`, `revised`.

نمره یا احتمال سیاسی خودکار تولید نمی‌شود. مرور زمان‌بندی‌شده، داده آرشیوی را خلاصه می‌کند و عدم وجود داده کافی را نشان می‌دهد؛ **خودش گردآوری و راستی‌آزمایی خبر جدید نیست**.

## پرسش از آرشیو
برای بازخوانی در ChatGPT به فایل‌های `research/knowledge.json` و `research/reports/...` و `daily/manifest.json` در مخزن GitHub متصل مراجعه شود؛ تاریخ، درجه اعتبار، منبع و تغییرات پیشین گزارش شوند. جست‌وجوی عمومی سایت در `fa/research/` است.
